👑 Dành riêng cho Lead Hoàng Sỹ Khiêm: Cách Check & Merge Branch

Khi các thành viên báo đã push branch xong, bạn chỉ cần chạy các lệnh sau (hoặc bảo trợ lý AI chạy giúp bạn):

# 1. Tải toàn bộ branch mới từ GitHub về máy Lead:
git fetch origin

# 2. Chuyển sang branch của thành viên để kiểm tra code (ví dụ branch của TV2):
git checkout feature/data-provenance

# 3. Chạy test thử xem code của bạn đó có làm hỏng test nào không:
pytest -v

# 4. Nếu test 100% pass, chuyển về main và merge:
git checkout main
git merge feature/data-provenance

# 5. Đẩy code đã merge lên GitHub main:
git push origin main
