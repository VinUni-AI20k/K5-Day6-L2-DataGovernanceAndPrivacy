1. Hoàng Sỹ Khiêm (Lead) ĐÃ XONG KHUNG CHÍNH
File: src/pipeline.py, configs/lab.yaml, src/main.py
  • Xây dựng pipeline 5 bước (load ➔ process ➔ rank ➔ review ➔ decide), Defect Recall đạt 85%.
  • Quản lý review và merge các branch của thành viên vào nhánh main.
2. Phú (Data & Baseline) NHẬN VIỆC
File: fixtures/t02_raw_qc/, tools/inspect_data.py
  • Thống kê 96 ảnh thô theo camera (cam_A, cam_B) và điều kiện ánh sáng (day, dusk, night).
  • Chạy baseline, ghi nhận 2 ca lỗi điển hình của baseline: ảnh đêm bị báo lỗi nhầm và ảnh lóa bị bỏ sót.
git checkout -b feature/phu-data
# Viết code tools/inspect_data.py xong chạy:
git add tools/inspect_data.py
git commit -m "feat(data): add dataset inspection and baseline failure analysis"
git push -u origin feature/phu-data
3. Hưng (Core Algorithm - cùng Khiêm) NHẬN VIỆC
File: src/pipeline.py
  • Rà soát thuật toán trong src/pipeline.py (Blur, Glare, Dark, Compression).
  • Bổ sung chú thích giải thích công thức toán các hàm tính điểm lỗi hoặc viết thêm hàm validate input.
git checkout -b feature/hung-core
# Chỉnh sửa src/pipeline.py xong chạy:
git add src/pipeline.py
git commit -m "feat(core): add technical docstrings and input validation helper"
git push -u origin feature/hung-core
4. Thiên (QA & Testing) NHẬN VIỆC
File: tests/test_t02_pipeline.py
  • Chạy pytest -v kiểm tra toàn bộ test suite.
  • Viết thêm 2 unit test cases kiểm tra trường hợp biên (ảnh bão hòa pixel 255, ảnh lúc hoàng hôn) trong tests/test_t02_pipeline.py.
git checkout -b feature/thien-qa
# Thêm test vào tests/test_t02_pipeline.py, chạy pytest -v xong chạy:
git add tests/test_t02_pipeline.py
git commit -m "test(t02): add unit tests for extreme glare and dusk edge cases"
git push -u origin feature/thien-qa
5. Đức (Human Review & Báo cáo) NHẬN VIỆC
File: reports/review_queue.csv, reports/group_report.md, reports/team_contributions.csv
  • Mở reports/review_queue.csv, điền tên "Đức" vào cột reviewer và viết nhận xét kiểm duyệt cho 20 ảnh.
  • Điền danh sách họ tên thật, MSSV, email của 5 thành viên vào reports/group_report.md.
  • Chuẩn bị 3–4 slide tóm tắt để nhóm thuyết trình.
git checkout -b feature/duc-report
# Chỉnh sửa xong chạy:
git add reports/review_queue.csv reports/group_report.md reports/team_contributions.csv
git commit -m "docs: audit review queue notes and update group member roster"
git push -u origin feature/duc-report
