# T09 · Multi-Market Privacy Decision Gate

**Độ khó:** CPU · dễ · **Topic Day06:** F1, F2, F3, H2 · **Fixture:** `fixtures/t09_privacy_gate/` · **Config:** `configs/tracks/t09.yaml`

> Policy engine offline (YAML/JSON có version + nguồn) đưa ra GO/HOLD/REWORK cho 12 case đa thị trường; người phụ trách phê duyệt cuối.

**5 bước bắt buộc:** Đọc case & thị trường → Load policy rule configs → Kiểm gap + risk flags → Human legal approval → Xuất audit checklist

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `cases/CASE-XX.json` | 12 case: market, data_types, lawful_basis, consent, notice, storage, transfer, retention, DPIA, ambiguity_notes. |
| `rules/policy_example.yaml` | **Ví dụ cấu trúc** rule (có `source`, `effective_date`, `reason_code`) — chưa đầy đủ, chưa kiểm chứng. |
| `README_disclaimer.md` | Đây là tình huống giả định học tập, không phải tư vấn pháp lý. |
| `gt/gold_decisions.csv` | Gold decision + reason codes của giảng viên — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** Không cần.

## 2. Output contract

`out/decisions.csv`: `case_id, decision ∈ {GO, HOLD, REWORK}, reason_codes` (phân tách `;`).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t09`)

- **Primary — Critical-miss Rate** = case rủi ro bị cho GO / tổng case rủi ro (giảm = tốt) ⇔ High-risk HOLD Recall.
- Secondary: false HOLD rate, exact decision accuracy, reason-code match, audit trace completeness. N rất nhỏ → báo từng case.

```bash
python -m src.evaluate --track t09 --pred out/decisions.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t09 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t09 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Sai có chủ ý: "có consent thì GO" — dùng để chứng minh checklist này không đủ (so false GO với GT).
- **Protocol:** Không hard-code luật tuỳ tiện trong code: rule file có version + nguồn điều khoản; ≥2 case ambiguity → HOLD.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Kết luận hợp pháp chỉ dựa vào consent; bỏ sót rủi ro chuyển dữ liệu xuyên biên giới.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Màn hình 12 case: thiếu bằng chứng, nguồn luật, escalation; người phụ trách phê duyệt cuối.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
