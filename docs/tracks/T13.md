# T13 · Active Learning & Rare Case Miner

**Độ khó:** CPU · trung bình · **Topic Day06:** G1, A2, D2 · **Fixture:** `fixtures/t13_rare_mining/` · **Config:** `configs/tracks/t13.yaml`

> Chọn K=20 ảnh đáng gán nhãn nhất từ pool 200 ảnh chưa nhãn, ưu tiên rare case thật, tránh duplicate và ảnh "lạ mà vô ích".

**5 bước bắt buộc:** Đọc feature & pool → Chấm novelty/uncertainty → Chọn K chống redundancy → Review subset → Xuất label queue & score

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `images/*.jpg` + `images.csv` | Pool 200 ảnh 256×144. |
| `pool_features.csv` | Feature rẻ (`brightness_*`, `saturation_mean`, `edge_density`) + `emb_00..15` (embedding giả lập). |
| `gt/rare_labels.csv` | 4 rare tags (night_rain, occluded_motorbike, construction, animal), junk, scene group — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/bdd/metadata.csv`: rare thật = foggy, tunnel, gas stations, parking lot, snowy+night — làm pool thật (tự khai báo GT = metadata BDD).

## 2. Output contract

`out/selected.csv`: `image_id` (K=20 dòng, tuỳ chọn `rank`).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t13`)

- **Primary — Rare-case Recall@K** = rare thật trong K / tổng rare trong pool.
- Secondary: unique-scene rate, % near-duplicate trong K, junk rate, dark-but-common rate.

```bash
python -m src.evaluate --track t13 --pred out/selected.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t13 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t13 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Random K=20, cùng pool & seed (có sẵn: `--pipeline src.examples.random_baseline`).
- **Protocol:** Không dùng rare GT khi rank; đánh giá cả hard-but-not-rare.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Chỉ chọn ảnh rất tối; ảnh độc lạ nhưng không giúp model (junk); duplicate đội lốt rare.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Contact sheet + confirm rare / false alarm; có thể xuất CVAT import format.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).

## 8. Gợi ý hướng nghiên cứu (không phải đáp án)

Density-weighted novelty (kNN distance) + dedupe (phash/embedding) + loại junk (noise/entropy); k-center greedy.

Slice `night_rain` và `occluded` của baseline đang bằng 0 — đây là **target** rõ ràng cho PoC; báo riêng từng slice, kể cả khi vẫn bằng 0.
