# T10 · Domain Shift Radar & Slice Dashboard

**Độ khó:** CPU · trung bình · **Topic Day06:** A3, G2, B1 · **Fixture:** `fixtures/t10_domain_shift/` · **Config:** `configs/tracks/t10.yaml`

> Chấm ShiftScore cho batch mới so với source sao cho tương quan với **độ sụt hiệu năng model**, không chỉ với "ảnh trông khác".

**5 bước bắt buộc:** Tính image descriptors → So source vs batch mới → Ước lượng risk score → Review risky slice → HOLD / KEEP & dashboard

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `batches/<batch>/*.jpg` + `images.csv` | 6 batch × 40 ảnh: source, night, rain, camera (tint+blur), city layout, dusk/người xa. |
| `model_predictions.csv` | Dự đoán (mô phỏng) cho task "có người đi bộ": `pred_score, pred_label`. |
| `gt/task_labels.csv`, `gt/batch_perf.csv` | Nhãn task + accuracy/perf_drop/high_risk theo batch — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/bdd/metadata.csv` + `detections.csv`: chia batch thật theo weather/timeofday (vd. daytime-clear làm source) — tự định nghĩa task proxy (vd. số pedestrian).

## 2. Output contract

`out/shift_scores.csv`: `batch_id, shift_score` (+ `pred_high_risk` 0/1).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t10`)

- **Primary — Spearman ρ(ShiftScore, PerformanceDrop)** trên 6 batch (kèm bootstrap CI) — hoặc AUROC high-risk (drop ≥ 0.10).
- Secondary: false-alarm rate, worst-slice detection, thời gian/batch.

```bash
python -m src.evaluate --track t10 --pred out/shift_scores.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t10 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t10 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Chỉ so độ sáng trung bình; cùng 6 batch và heldout task GT.
- **Protocol:** Phải chứng minh shift liên hệ hiệu năng, không chỉ ảnh khác; khoá threshold trước evaluation.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Shift lớn nhưng không ảnh hưởng model (có batch như vậy!); rủi ro âm thầm ở slice nhỏ.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Dashboard group-by batch/điều kiện; giải thích HOLD và false alarm.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
