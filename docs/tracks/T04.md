# T04 · Sensor Sync Guard: đồng bộ camera và IMU

**Độ khó:** CPU · trung bình · **Topic Day06:** C1, C2, C3 · **Fixture:** `fixtures/t04_sensor_sync/` · **Config:** `configs/tracks/t04.yaml`

> Ước lượng offset/drift giữa clock camera (30 Hz) và IMU (100 Hz), ghép cặp frame–IMU đúng sự kiện, HOLD đoạn mất sensor.

**5 bước bắt buộc:** Đọc 2 luồng timestamp → Ước lượng offset → Ghép cặp & lọc sai → Review đoạn khả nghi → Xuất sync report

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `camera.csv` | `frame_id, t_cam_s` (**giây**), `exposure_ms, motion_score`. |
| `imu.csv` | `t_imu_ms` (**mili-giây**), `ax..gz`. |
| `segments.csv` | 6 đoạn × 20 s, split dev/eval theo đoạn. |
| `README_units.md` | **Đọc kỹ đơn vị.** |
| `shock/` | Bài shock test: camera clock reset giữa chừng. |
| `gt/gt_pairs.csv` | `gt_imu_t_ms` đúng cho mỗi frame (NaN khi IMU dropout), offset thật, drift — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** Không có gói real cho track này (nuScenes cần đăng ký) — dùng fixture.

## 2. Output contract

`out/pairs.csv`: `frame_id, imu_t_ms` (timestamp IMU được ghép; **để trống = HOLD**).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t04`)

- **Primary — Pair Accuracy@50ms** = #frame có |pred − GT| ≤ 50 ms / #frame có GT partner (split eval). HOLD tính là sai.
- Secondary: median |residual| (ms), bad-pair recall (frame dropout được HOLD), % frame HOLD.

```bash
python -m src.evaluate --track t04 --pred out/pairs.csv
python -m src.evaluate --track t04 --gt fixtures/t04_sensor_sync/gt/shock_gt_pairs.csv --pred out/pairs_shock.csv --split all
# lưu kết quả để nộp:
python -m src.evaluate --track t04 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t04 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Nearest-timestamp join không hiệu chỉnh offset, tolerance cố định trước thử nghiệm.
- **Protocol:** 50% stream dev / 50% eval theo segment; không nhìn GT offset eval khi tune.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Sai đơn vị ms/s; tự nối cặp khi sensor dropout; ghép đúng timestamp nhưng sai event; clock reset.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Plot offset theo thời gian + 5 cặp lỗi để người vận hành xác nhận.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
