# T14 · Auto-Annotation + Human QC Exporter

**Độ khó:** CPU · trung bình · **Topic Day06:** G3, E1, H3 · **Fixture:** `fixtures/t14_auto_annotation/` · **Config:** `configs/tracks/t14.yaml`

> Dùng prediction có sẵn để pre-annotate, lọc theo confidence, ưu tiên box bất định cho người sửa, export YOLO/COCO hợp lệ.

**5 bước bắt buộc:** Auto infer boxes/classes → Lọc confidence threshold → Rank uncertain & mismatch → Human sửa labels → Export YOLO/COCO + QA

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `images/*.jpg` + `images.csv` | 60 ảnh, 20 ảnh eval tách trước. |
| `taxonomy.yaml` | Taxonomy dự án: car, pedestrian, motorbike, sign. |
| `model_predictions_fixture.csv` | Prediction **mô phỏng** với `class_id` theo **label map của model** (COCO-style) — khác taxonomy! |
| `model_card_fixture.yaml` | Nguồn/version/label map của fixture. |
| `gt/gt_boxes.csv` | Box đúng — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/coco` hoặc `data/real/bdd/detections.csv` làm GT thật; YOLO26n weights nếu giảng viên preload (`models_optional/`, ghi checksum/license).

## 2. Output contract

`out/predictions.csv` (nhãn export cuối): `image_id, class, x, y, w, h` (+ `conf`), `class` theo **tên trong taxonomy**.

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t14`)

- **Primary — Detection F1@IoU0.5** trên 20 ảnh eval (match greedy, đúng class).
- Secondary: invalid-label rate sau export, review minute/image, correction gain ΔF1, recall theo class & object nhỏ.

```bash
python -m src.evaluate --track t14 --pred out/predictions.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t14 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t14 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Auto-predict threshold mặc định + export không review.
- **Protocol:** Ghi weights/model version/license; fixture prediction được dùng để test pipeline nhưng **không** được báo như inference thật.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Mapping class ID sai vẫn export hợp lệ; conf cao nhưng thiếu object nhỏ.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Bảng low-confidence boxes + approve/edit/delete + diff + QA sample.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
