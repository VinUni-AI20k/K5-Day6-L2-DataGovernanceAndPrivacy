# T01 · Coverage Planner: chọn đủ cảnh cần thu

**Độ khó:** CPU · dễ · **Topic Day06:** A1, A2, H3 · **Fixture:** `fixtures/t01_coverage/` · **Config:** `configs/tracks/t01.yaml`

> Từ 120 clip ứng viên, chọn K clip để phủ tối đa 15 ô coverage mục tiêu (có trọng số rủi ro), rồi lập capture plan cho ô còn thiếu.

**5 bước bắt buộc:** Đọc CSV + quy tắc → Đếm coverage & ô thiếu → Chọn K clip ưu tiên → Human review 3 ô rủi ro → Xuất capture plan + metrics

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `candidates.csv` | 120 clip: `clip_id, route, weather, light, object, risk, cost_min, duration_s`. **Metadata planner nhìn thấy** — ~12% tag bị nhiễu/`unknown`. |
| `targets.csv` | 15 ô mục tiêu `cell_id, route, weather, light, object, weight, is_hard` (`*` = wildcard). Trọng số **chốt trước**, không sửa sau khi xem kết quả. |
| `holdout_candidates.csv` | 25 clip giữ riêng (K=6) để kiểm tra rule có tổng quát không. |
| `gt/verified_tags.csv`, `gt/holdout_verified_tags.csv` | Tag đã kiểm chứng — chỉ `src.evaluate` dùng. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/bdd/metadata.csv` có weather/timeofday/scene thật của BDD100K — có thể dựng target matrix thật (không có GT ẩn; tự khai báo protocol).

## 2. Output contract

`out/pick.csv`: `clip_id` (K dòng; tuỳ chọn `rank`).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t01`)

- **Primary — Weighted Coverage@K** = Σ trọng số ô mục tiêu được phủ / Σ trọng số mọi ô mục tiêu (tăng = tốt). Clip phủ ô nếu tag *verified* khớp mọi chiều (hoặc `*`).
- Secondary: Rare-scenario Recall@K (ô `is_hard` được phủ / số ô hard), số clip trùng kịch bản, chi phí (phút) / ô được phủ.

```bash
python -m src.evaluate --track t01 --pred out/pick.csv
python -m src.evaluate --track t01 --gt fixtures/t01_coverage/gt/holdout_verified_tags.csv --pred out/pick_holdout.csv --k 6
# lưu kết quả để nộp:
python -m src.evaluate --track t01 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t01 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Random chọn K clip, seed 42, cùng K và cùng pool. (Có sẵn ví dụ: `--pipeline src.examples.random_baseline`.)
- **Protocol:** K = 30/120. Không đổi trọng số sau khi nhìn kết quả. Báo cáo cả budget 10/20/30 (mốc 24h).
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Ô vẫn thiếu dù nhiều ảnh (có ô **không thể phủ** bằng pool hiện tại → phải đưa vào capture plan); chọn lại toàn cảnh giống nhau; metadata sai làm tưởng đã phủ.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Bảng ô còn thiếu + 3 đề xuất quay bổ sung + người duyệt kế hoạch (owner, reason).
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).

| Mốc 180 phút (đủ demo) | Deadline +24h |
|---|---|
| CLI sinh `coverage.csv`, `pick.csv`, bar chart so baseline. | Phân tích hiệu quả theo budget 10/20/30; shot list ưu tiên chi phí. |

## 8. Gợi ý hướng nghiên cứu (không phải đáp án)

Greedy weighted set cover; xử lý tag `unknown` (phạt / gửi review); cost-aware selection; marginal gain per minute.

Báo coverage theo trọng số rủi ro và so với **baseline greedy set-cover** (không chỉ random) — greedy là baseline mạnh và dễ cài; PoC không thắng greedy thì phải nói rõ.
