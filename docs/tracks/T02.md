# T02 · Raw QC Triage: ảnh mờ, lóa và thiếu sáng

**Độ khó:** CPU · dễ · **Topic Day06:** B1, B2, D1 · **Fixture:** `fixtures/t02_raw_qc/` · **Config:** `configs/tracks/t02.yaml`

> Xếp hạng ảnh nghi lỗi (blur / glare / dark / compression) để người review B=20 ảnh tìm được nhiều lỗi nhất; quyết định KEEP / RECAPTURE.

**5 bước bắt buộc:** Đọc ảnh + metadata → Tính blur/brightness/… → Xếp hạng REVIEW → Audit ảnh nghi ngờ → Báo KEEP / RECAPTURE

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `images/*.jpg` + `images.csv` | 96 ảnh synthetic 320×180 từ 24 cảnh gốc: `image_id, path, camera_id, light, split` (dev 60% / eval 40% **theo cảnh gốc**). |
| `gt/labels.csv` | `defect_type ∈ {none, blur, glare, dark, compression}`, `severity 0–2`, `is_defect` — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/bdd/images` (ảnh thật nhiều điều kiện) + `src/common/corruptions.py` để inject lỗi có log — ảnh đêm thật là hard negative tốt.

## 2. Output contract

`out/ranked_review.csv`: `image_id, score` (score cao = nghi lỗi hơn); tuỳ chọn `pred_defect_type, pred_action`.

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t02`)

- **Primary — Defect Recall@B** (B=20, trên split eval) = #ảnh lỗi thật trong top-B / #ảnh lỗi thật; kèm **Precision@B**.
- Secondary: false alarm trong top-B theo slice `light` (day/dusk/night), defect-type accuracy, ms/ảnh.

```bash
python -m src.evaluate --track t02 --pred out/ranked_review.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t02 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t02 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Một ngưỡng Laplacian toàn ảnh duy nhất (`src/common/image_ops.laplacian_variance`), cùng testset & budget.
- **Protocol:** Chỉnh threshold chỉ trên split `dev`; không dùng nhãn eval để tune.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Ảnh ban đêm hữu ích bị loại hết; ảnh nét nhưng vùng biển số cháy sáng (glare cục bộ) bị bỏ qua; camera có quang học mềm hơn (cam_B) bị báo nhầm.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Contact sheet 20 ảnh ưu tiên: score, ảnh, loại lỗi, override (dùng `src/common/contact_sheet.py`).
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
