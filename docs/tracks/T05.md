# T05 · Leakage & Near-Duplicate Guardian

**Độ khó:** CPU · dễ · **Topic Day06:** D2, A2, H3 · **Fixture:** `fixtures/t05_near_duplicate/` · **Config:** `configs/tracks/t05.yaml`

> Phát hiện exact/near-duplicate và burst, gom nhóm, rồi tạo split train/test không leakage theo scene.

**5 bước bắt buộc:** Hash file + perceptual hash → Graph nhóm trùng → Đề xuất group train/test → Audit cặp false-positive → Xuất split không leakage

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `images/*.jpg` + `images.csv` | 120 ảnh, 20 scene: `image_id, path, camera_id, captured_at` (không có scene_id!). |
| `gt/gt_groups.csv` | `scene_id, dup_group_id, transform` — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** Tự tạo near-dup từ `data/real/bdd/images` (crop/brightness/re-encode) và log trong manifest.

## 2. Output contract

`out/suspect_pairs.csv`: `img_a, img_b` (+ `score`, `pred_dup` 0/1). Thêm `out/split_manifest.csv`: `image_id, split ∈ {train, test, drop}` để chấm leakage sau split.

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t05`)

- **Primary — Leakage Detection F1 (đơn vị = cặp ảnh không thứ tự cùng near-dup group)**.
- Secondary: residual cross-split leak (near-dup & cùng scene), false merge rate (cặp khác scene), % dữ liệu giữ lại.

```bash
python -m src.evaluate --track t05 --pred out/suspect_pairs.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t05 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t05 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Random split theo ảnh độc lập; thêm exact-hash baseline (`sha256`) khi so near-dup.
- **Protocol:** Có ≥2 dạng leak (exact và transformed/near). Không chia frame cùng scene ra hai split để tăng điểm giả.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Merge hai scene khác nhau vì màu giống nhau (có trap!); leakage vẫn còn sau group split.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Contact sheet các cặp nghi ngờ + approve group / reject match.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
