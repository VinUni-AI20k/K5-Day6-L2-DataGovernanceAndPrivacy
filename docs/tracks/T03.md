# T03 · Synthetic-vs-Real: tạo và kiểm dữ liệu khó

**Độ khó:** CPU · trung bình · **Topic Day06:** B3, B1, B2 · **Fixture:** `fixtures/t03_synthetic/` · **Config:** `configs/tracks/t03.yaml`

> Sinh biến thể night/glare/fog/blur có provenance đầy đủ và một quality gate phát hiện ảnh biến đổi vượt ngưỡng usability.

**5 bước bắt buộc:** Đọc ảnh gốc → Sinh 4 kiểu biến đổi → Ghi manifest provenance → QC theo severity → Đề xuất mix train/hold

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `originals/*.jpg` + `originals.csv` | 30 ảnh gốc (20 dev + 10 holdout). |
| `objects.csv` | bbox đối tượng trong ảnh gốc — dùng để kiểm tra "đối tượng biến mất". |
| `transform_config.example.yaml` | Ví dụ cấu hình (seed cố định). |
| `README_usability_rule.md` | **Rule usability đã chốt** dùng để tạo GT. |
| `holdout_transformed/` + `.csv` | 45 ảnh holdout đã biến đổi (gồm cả `erase`) để chấm QC. |
| `gt/holdout_gt.csv` | transform, severity, seed, `unusable` — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** Ảnh BDD thật trong `data/real/bdd` làm ảnh gốc; ảnh thời tiết thật (rainy/foggy/snowy) để thảo luận sim-to-real gap.

## 2. Output contract

`out/qc.csv`: `image_id, pred_unusable` (0/1) cho ảnh trong `holdout_transformed/`. Thêm `out/transform_manifest.csv` để được chấm provenance completeness.

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t03`)

- **Primary — Transform QC F1** (positive = unusable theo rule đã chốt).
- Secondary: precision/recall, số ảnh `erase` (label sai) bị lọt, provenance completeness, thời gian xử lý.

```bash
python -m src.evaluate --track t03 --pred out/qc.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t03 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t03 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Mix augmentation ngẫu nhiên, không lưu provenance, không phân mức severity.
- **Protocol:** 20 ảnh dev + 10 holdout. Không gọi augmentation là "thời tiết thật".
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Synthetic làm mất đối tượng nhưng vẫn giữ label; thiếu trace transform.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.
