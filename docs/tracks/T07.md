# T07 · Automatic Face/Plate Redaction + Review Queue

**Độ khó:** CPU · trung bình · **Topic Day06:** E1, E2, G3 · **Fixture:** `fixtures/t07_redaction/` · **Config:** `configs/tracks/t07.yaml`

> Tự động che mặt/biển số, xếp hàng vùng nghi ngờ cho người duyệt, đo tỉ lệ bỏ sót theo slice nguy hiểm.

**5 bước bắt buộc:** Detect face/plate → Blur/mask đủ coverage → Xếp hàng low confidence → Human review & sửa vùng → Export ảnh + audit log

## 1. Dữ liệu có sẵn (offline)

| File | Nội dung |
|---|---|
| `images/*.jpg` + `images.csv` | 60 ảnh synthetic 640×360 (mặt hoạt hình, biển số giả `SYN-…`) — **không có PII thật**; split dev/eval. |
| `gt/gt_regions.csv` | ~330 vùng `face/plate` + `condition ∈ {normal, small, dark, blur, occluded}` — chỉ evaluate. |

`manifest.csv` (input) và `gt/manifest.csv` (ground truth) chứa `source, license, split, sha256` — pipeline kiểm hash ở bước load.
**Pipeline không được đọc `gt/`** (GT guard trong `src.main` sẽ dừng với exit code 5).

**Dữ liệu thật (tuỳ chọn, nếu giảng viên đã chuẩn bị `data/real/`):** `data/real/plates/` (60 ảnh biển số thật, CC BY 4.0) + `plate_regions.csv` — **chỉ dùng local**. Đầu người đi bộ trong fixture là hard negative (nhìn từ phía sau, không phải PII theo GT).

## 2. Output contract

`out/redactions.csv`: `image_id, x, y, w, h` — vùng **đã che cuối cùng** (sau review).

`src.main` kiểm tra file và cột bắt buộc; thiếu → exit code 2.

## 3. Metric (đã cài sẵn trong `src/metrics/tracks.py::eval_t07`)

- **Primary — PII Miss Rate** = #vùng GT có pixel coverage < 0.9 / #vùng GT (giảm = tốt), báo theo slice `type` và `condition`.
- Secondary: region recall, over-redaction rate (pixel che ngoài GT / pixel che), Recall@B của hàng chờ (B=15), images/s.

```bash
python -m src.evaluate --track t07 --pred out/redactions.csv
# lưu kết quả để nộp:
python -m src.evaluate --track t07 --pred out/baseline/<file> --run-name baseline --out reports/metrics_baseline.json
python -m src.evaluate --track t07 --pred out/poc/<file>      --run-name poc      --out reports/metrics_poc.json
python -m src.compare reports/metrics_baseline.json reports/metrics_poc.json --out reports/table1_baseline_vs_poc.md
```

## 4. Baseline (nhóm tự cài) + thí nghiệm công bằng

- **Baseline:** Detector mặc định + blur cố định, không queue/human audit; cùng GT.
- **Protocol:** Không đo "mờ nhìn được" bằng cảm giác — đo pixel coverage theo GT. 60% dev / 40% eval.
- Cùng pool / budget / seed 42 / heldout cho baseline và PoC. Báo cả kết quả bằng 0 hoặc âm.

## 5. Failure mode bắt buộc phải phân tích

Bỏ sót mặt nhỏ trong bóng tối; che quá rộng mất tín hiệu task; upload raw PII lên cloud.

Fixture đã cài sẵn một số case cho các failure mode này — nhóm phải tự tìm, minh hoạ bằng ảnh/metadata và nêu root cause.

## 6. Human review + quyết định

Contact sheet vùng nghi ngờ: trước/sau, score, add/edit/redact, re-export.
Dùng `src/common/review.py` (queue, overrides, `AuditLog`), `src/common/contact_sheet.py` (HTML offline có nút Export CSV) và `src/common/decision.py` (GO/HOLD/REWORK + `reason_code` + `owner`).
